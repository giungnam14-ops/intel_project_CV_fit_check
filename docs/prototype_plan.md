# FitCheck AI Prototype Plan

> [!NOTE]
> **현재 단계: 코드 구현 전 프로토타입 기획 단계**
> 본 문서는 실제 웹/앱 코드 개발 이전에 사용자가 경험할 화면 흐름과 프로토타입(Figma, Canva, PPT 등 활용) 시안 제작을 위한 가이드입니다.

## 1. 프로토타입 목표
- **사용자 경험(UX) 검증:** 초보 홈트레이닝 사용자가 직관적으로 서비스를 이해하고 흐름을 따라갈 수 있는지 확인
- **핵심 가치 전달:** 진단이나 평가 같은 무거운 느낌을 배제하고, '더 안정적인 자세'와 '초보자 맞춤 자세 코칭'이라는 친근한 서비스 핵심 가치를 화면을 통해 전달
- **피드백 수집:** 본격적인 AI(MediaPipe) 모델 연동 및 코드 구현 전, 화면 시나리오에 대한 사용자/이해관계자의 피드백 수집 및 반영

## 2. 전체 화면 흐름
화면 시안 제작을 위한 최소 4개의 핵심 화면으로 구성됩니다.
1. `메인 화면 (운동 선택 포함)` 
2. `카메라 세팅 가이드 화면` 
3. `실시간 자세 분석 화면 (코칭 피드백 팝업 포함)` 
4. `운동 결과 리포트 화면`

---

## 3. 화면별 상세 구성 (Canva/Figma 시안 제작용)

### 3.1. 메인 화면
* **화면 목적:** 서비스의 첫인상을 전달하고, 사용자가 원하는 운동을 선택하여 바로 시작할 수 있도록 유도
* **화면 레이아웃:** 
  * 상단: 서비스 로고 및 헤더 일러스트/메시지
  * 중단: 운동 선택 카드 리스트 (좌우 스와이프 형태)
  * 하단: 글로벌 네비게이션 바
* **주요 UI 요소:**
  * 서비스 로고 (FitCheck AI)
  * 친근한 홈트레이닝 일러스트
  * 운동 선택 카드 (스쿼트 등)
    * 카드 내 표시 항목: 난이도, 촬영 방향, 코칭 포인트, 준비물
* **화면에 들어갈 문구:**
  * 헤더: "내 자세를 확인하며 운동하기, 초보자 맞춤 자세 코칭 FitCheck AI"
  * 스쿼트 카드: 
    * 난이도: ⭐⭐ (초보자 추천)
    * 촬영 방향: 측면 촬영
    * 코칭 포인트: 무릎과 발끝 방향, 엉덩이 위치
    * 준비물: 없음 (맨몸)
* **다음 화면으로 넘어가는 버튼:**
  * [스쿼트 코칭 시작하기] 버튼 ➡️ `카메라 세팅 가이드 화면`으로 이동

### 3.2. 카메라 세팅 가이드 화면
* **화면 목적:** AI가 사용자의 관절을 정확하게 인식할 수 있도록 최적의 카메라 위치와 복장을 안내
* **화면 레이아웃:** 
  * 상단: 타이틀 및 안내 문구
  * 중단: 스마트폰 거치 일러스트 및 반투명 인체 실루엣(측면)
  * 하단: 주의사항 텍스트 체크리스트 및 확인 버튼
* **주요 UI 요소:**
  * 스마트폰 바닥 거치 일러스트 (바닥에서 약 70cm 높이)
  * 측면 전신 실루엣 가이드라인
  * 체크리스트 아이콘 (옷차림, 관절 노출 여부 등)
* **화면에 들어갈 문구:**
  * 타이틀: "더 정확한 코칭을 위해 카메라를 세팅해주세요."
  * 안내 (체크리스트): 
    * "측면 촬영 권장: 측면에서 찍어야 정확한 코칭이 가능해요."
    * "머리부터 발끝까지 화면 안에 들어오게 맞춰주세요."
    * "무릎, 엉덩이, 발목 관절이 가려지지 않아야 해요."
    * "너무 어둡거나 헐렁한 옷은 AI가 인식하기 어려울 수 있어요."
* **다음 화면으로 넘어가는 버튼:**
  * [준비 완료] 버튼 ➡️ `실시간 자세 분석 화면`으로 이동

### 3.3. 실시간 자세 분석 화면 (운동 중)
* **화면 목적:** 사용자가 운동을 수행하는 동안 실시간으로 스켈레톤을 보여주고, 필요시 코칭 배너를 띄워 자세 개선을 도움
* **화면 레이아웃:** 
  * 전체: 카메라 실시간 프리뷰
  * 상단: 현재 횟수 표시 및 일시정지 아이콘
  * 중단: 인체 스켈레톤 라인 (프리뷰 위에 오버레이)
  * 하단: 실시간 코칭 피드백 팝업/배너 (운동 중 수시로 나타남)
* **주요 UI 요소:**
  * 부드러운 스켈레톤 그래픽 (파스텔 톤, 둥근 느낌)
  * 실시간 카운트 UI (예: 5 / 10회)
  * 코칭 피드백 배너 (문제가 된 부위 하이라이트 아이콘 포함)
  * [운동 종료] 버튼 (또는 [일시정지] 버튼 클릭 시 노출)
* **화면에 들어갈 문구:**
  * 상단: "현재 스쿼트 5회째"
  * 코칭 배너 (긍정): "안정적인 자세예요! 계속 진행해보세요."
  * 코칭 배너 (개선 필요): "엉덩이를 조금만 더 뒤로 빼볼까요? 의자에 앉는다는 느낌으로!"
* **다음 화면으로 넘어가는 버튼:**
  * [운동 종료] 버튼 ➡️ `운동 결과 리포트 화면`으로 이동

### 3.4. 운동 결과 리포트 화면
* **화면 목적:** 운동 완료 후 성취감을 제공하고, 다음 운동 시 참고할 수 있는 코칭 조언을 전달
* **화면 레이아웃:** 
  * 상단: 축하 애니메이션 및 요약 수치
  * 중단: 자세 안정성 점수 및 원포인트 어드바이스
  * 하단: 액션 버튼
* **주요 UI 요소:**
  * 칭찬 스티커 또는 뱃지 이미지
  * 운동 요약 데이터 (횟수, 시간)
  * 부드러운 톤의 점수판 (자세 안정성)
  * 원포인트 코칭 텍스트 박스
* **화면에 들어갈 문구:**
  * 타이틀: "수고하셨습니다! 오늘도 꾸준히 해냈어요 👏"
  * 요약: "총 15회 / 5분 소요"
  * 점수: "오늘의 자세 안정성: 85점"
  * 원포인트 어드바이스: "전체적으로 안정적이에요! 다음번엔 허리를 조금 더 곧게 펴고 진행해보세요."
* **다음 화면으로 넘어가는 버튼:**
  * [홈으로 가기] 버튼 ➡️ `메인 화면`으로 이동

## 4. 피드백 받을 질문 목록
1. 처음 메인 화면에 진입했을 때, 이 앱이 '초보자 맞춤 자세 코칭'을 해준다는 것이 잘 느껴지나요?
2. 카메라 세팅 가이드의 4가지 조건이 직관적이고 이해하기 쉽나요?
3. 실시간 분석 화면에서 하단 배너로 뜨는 피드백이 운동에 방해가 되지는 않나요?
4. 코칭 피드백 문구가 평가받는 느낌이 아니라 부드러운 조언으로 느껴지나요?
5. 결과 리포트를 보았을 때, 내일도 다시 이 앱을 켜서 운동하고 싶은 동기부여가 되나요?

## 5. 이번 프로토타입에서 제외할 기능
* 회원가입 및 로그인 절차 화면 (앱 실행 시 바로 메인 화면 진입으로 가정)
* 복잡한 캘린더 형태의 과거 운동 기록 통계 화면
* 소셜 미디어 친구 초대 및 상세 공유 기능
* 프로필 설정 및 앱 내 세부 환경설정(알림 등) 화면
