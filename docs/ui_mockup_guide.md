# FitCheck AI - 모바일 앱 화면 시안 제작 가이드

> [!NOTE]
> **디자인 방향성 (Design System)**
> - **분위기:** 초보 홈트 사용자가 편안하게 느낄 수 있는 밝고 부드러운 분위기 (의료/진단 느낌 배제)
> - **메인 컬러:** 파스텔 블루(신뢰, 안정감), 민트(상쾌함, 건강함)
> - **배경/서브 컬러:** 화이트(깔끔함), 연한 그레이(구분선 및 비활성 요소)
> - **형태:** 모든 버튼, 카드, 배너, 스켈레톤 라인은 모서리가 둥근(Rounded) 형태 적용
> - **말투:** 전문 코치가 옆에서 친절하게 알려주는 듯한 부드럽고 격려하는 톤

---

## 1. 메인 화면

* **화면 목적:** 서비스의 첫인상을 전달하고, 사용자가 원하는 운동을 선택하여 바로 시작할 수 있도록 유도
* **레이아웃 구조:**
  * **상단 영역:** 서비스 로고, 친근한 홈트레이닝 일러스트 및 메인 메시지
  * **본문 영역:** 운동 선택 카드 리스트 (좌우 스와이프 형태 캐러셀)
  * **하단 영역:** 글로벌 네비게이션 바 (홈, 기록, 마이페이지)
* **추천 UI 요소:**
  * 상단 여백이 넉넉한 둥근 모서리의 일러스트 박스
  * 그림자가 살짝 들어간 운동 카드 UI (입체감 부여)
  * 둥근 형태의 메인 CTA 버튼
* **화면에 들어갈 실제 문구:**
  * 헤더: "내 자세를 확인하며 운동하기\n초보자 맞춤 자세 코칭 FitCheck AI"
  * 스쿼트 카드:
    * "스쿼트"
    * 난이도: ⭐⭐ (초보자 추천)
    * 촬영 방향: 측면 촬영
    * 코칭 포인트: 무릎과 발끝 방향, 엉덩이 위치
    * 준비물: 없음 (맨몸)
  * 버튼: [스쿼트 코칭 시작하기]
* **추천 색감:** 
  * 배경: 화이트 (#FFFFFF)
  * 상단 일러스트 배경: 아주 연한 파스텔 블루 (#F0F8FF)
  * 시작 버튼: 민트 포인트 컬러 (#48C9B0)
* **추천 아이콘/일러스트:**
  * 상단: 요가 매트 위에서 스트레칭을 하거나 스쿼트를 준비하는 둥글고 귀여운 캐릭터
  * 아이콘: 별(난이도), 스마트폰(촬영 방향), 타겟(코칭 포인트), 덤벨(준비물)
* **Canva/Figma 제작 팁:**
  * 카드 UI 컴포넌트를 만들 때 Corner Radius(모서리 둥글기)를 16~24px 정도로 넉넉하게 주세요.
  * 텍스트에 다크 그레이(#333333)를 사용하여 완전한 검은색(#000000)보다 부드러운 느낌을 주세요.

## 2. 카메라 세팅 가이드 화면

* **화면 목적:** AI가 사용자의 관절을 정확하게 인식할 수 있도록 최적의 카메라 위치와 복장을 안내
* **레이아웃 구조:**
  * **상단 영역:** 화면 타이틀 및 서브 텍스트
  * **본문 영역:** 스마트폰 거치 일러스트 및 반투명 인체 실루엣(측면)
  * **하단 영역:** 주의사항 체크리스트 텍스트 박스, 하단 고정 버튼
* **추천 UI 요소:**
  * 시각적 이해를 돕는 바닥 거치 일러스트 중앙 배치
  * 점선으로 표시된 전신 실루엣 가이드라인
  * 체크 아이콘이 포함된 텍스트 리스트
* **화면에 들어갈 실제 문구:**
  * 타이틀: "더 정확한 코칭을 위해\n카메라를 세팅해주세요."
  * 체크리스트:
    * "✓ 측면 촬영 권장: 측면에서 찍어야 정확한 코칭이 가능해요."
    * "✓ 전신 노출: 머리부터 발끝까지 화면 안에 들어오게 맞춰주세요."
    * "✓ 관절 노출: 무릎, 엉덩이, 발목 관절이 가려지지 않아야 해요."
    * "✓ 의상 주의: 너무 어둡거나 헐렁한 옷은 AI가 인식하기 어려울 수 있어요."
  * 버튼: [준비 완료]
* **추천 색감:**
  * 배경: 화이트 (#FFFFFF)
  * 체크리스트 배경: 연한 회색 박스 (#F8F9FA)
  * 하단 버튼: 파스텔 블루 (#5DADE2)
* **추천 아이콘/일러스트:**
  * 본문: 스마트폰을 물건에 기대어 바닥에 둔 친근한 일러스트, 실루엣은 사람 형태의 부드러운 곡선
  * 체크리스트: 동그란 원 안의 민트색 체크 마크
* **Canva/Figma 제작 팁:**
  * 일러스트와 실루엣 가이드라인이 가장 돋보이도록 중앙에 크게 배치하세요.
  * 체크리스트는 글씨를 너무 작지 않게, 줄 간격을 1.5배 정도로 넓게 주어 가독성을 높이세요.

## 3. 실시간 자세 분석 화면 (운동 중)

* **화면 목적:** 운동을 수행하는 동안 실시간으로 부드러운 스켈레톤을 보여주고, 코칭 배너로 자세 개선을 도움
* **레이아웃 구조:**
  * **상단 영역:** 현재 횟수 표시(중앙), 일시정지 아이콘(우측 상단)
  * **본문 영역:** 전체 화면 카메라 프리뷰 배경, 인체 스켈레톤 라인 오버레이
  * **하단 영역:** 실시간 코칭 피드백 팝업/배너 (프리뷰 하단에 플로팅), 종료 버튼
* **추천 UI 요소:**
  * 카메라 프리뷰 뷰포트 (Figma/Canva에서는 운동하는 사람의 실제 사진 플레이스홀더 사용)
  * 둥글고 도톰한 두께의 스켈레톤 선 (관절점은 부드러운 원형)
  * 둥근 모서리의 플로팅 배너(팝업창)
* **화면에 들어갈 실제 문구:**
  * 상단: "현재 스쿼트 5회째"
  * 긍정 코칭 배너: "🌟 안정적인 자세예요! 계속 진행해보세요."
  * 개선 코칭 배너: "💡 엉덩이를 조금만 더 뒤로 빼볼까요? 의자에 앉는다는 느낌으로!"
  * 버튼: [운동 종료]
* **추천 색감:**
  * 스켈레톤 선: 부드러운 민트 (#48C9B0) 또는 화이트 라인, 관절점은 흰색/민트색 원
  * 긍정 코칭 배너: 연한 민트 배경 + 진한 초록 텍스트
  * 개선 코칭 배너: 연한 노랑/오렌지 배경 + 진한 브라운 텍스트
  * 상단 카운트 UI: 반투명 검정 배경 박스 (#000000 40%) + 흰색 텍스트
* **추천 아이콘/일러스트:**
  * 배너 아이콘: 반짝이는 별표(긍정), 전구 모양 아이콘(개선 팁)
  * 일시정지: 둥근 모서리의 일시정지(II) 아이콘
* **Canva/Figma 제작 팁:**
  * 뼈다귀(스켈레톤)를 기계적인 느낌이 나지 않게 라인 두께를 두껍게 하고 양끝을 둥글게(Round Cap) 처리하세요.
  * 코칭 배너는 화면 하단에서 둥둥 떠 있는 느낌이 들도록 부드러운 드롭 섀도우를 적용하세요.

## 4. 운동 결과 리포트 화면

* **화면 목적:** 운동 완료 후 성취감을 제공하고, 다음 운동 시 참고할 수 있는 코칭 조언을 전달
* **레이아웃 구조:**
  * **상단 영역:** 축하 애니메이션(일러스트) 및 운동 요약 수치
  * **본문 영역:** 자세 안정성 점수 카드, 원포인트 코칭 어드바이스 카드
  * **하단 영역:** 메인 액션 버튼
* **추천 UI 요소:**
  * 화려하지 않고 따뜻한 느낌의 축하 일러스트
  * 정보가 명확히 분리된 부드러운 형태의 카드형 UI
* **화면에 들어갈 실제 문구:**
  * 타이틀: "수고하셨습니다!\n오늘도 꾸준히 해냈어요 👏"
  * 요약: "총 15회 / 5분 소요"
  * 점수 타이틀: "오늘의 자세 안정성"
  * 점수: "85점" (숫자를 크고 둥근 서체로 강조)
  * 어드바이스: "전체적으로 안정적이에요! 다음번엔 허리를 조금 더 곧게 펴고 진행해보세요."
  * 버튼: [홈으로 가기]
* **추천 색감:**
  * 배경: 아주 연한 파스텔 블루 (#EAF2F8) 또는 화이트
  * 점수 카드: 화이트 배경 + 메인 컬러 텍스트
  * 어드바이스 카드: 연한 민트 배경 (#E8F8F5) + 다크 그레이 텍스트
* **추천 아이콘/일러스트:**
  * 상단: 왕관을 쓴 캐릭터 또는 귀여운 뱃지/스티커 일러스트
  * 어드바이스 카드: 코치 모자나 호각을 단 귀여운 캐릭터 아이콘
* **Canva/Figma 제작 팁:**
  * 점수 카드와 어드바이스 카드를 위아래로 배치하여 정보의 위계를 명확히 하세요.
  * '점수'라는 단어가 너무 냉정한 평가처럼 느껴지지 않도록, 두껍고 귀여운 폰트를 사용하여 성취감을 높이세요.
