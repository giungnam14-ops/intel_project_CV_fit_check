## 1. 배경 (Background)

### 1.1 문제 요약
홈트 초보자들이 운동 중 자신의 자세가 정확한지 실시간으로 알지 못해 무릎/허리 부담 가능성과 성취감 저하를 겪고 있음.

### 1.2 비전 요약
웹캠 하나로 실시간 관절 각도를 분석하여 정석 자세와 안정성을 코칭해주는 AI 운동 파트너.

### 1.3 대표 시나리오
사용자가 카메라 앞에서 스쿼트를 할 때, AI가 실시간으로 각도를 계산하여 부족한 부분을 한국어 메시지로 즉시 알려주는 장면.

### 1.4 이 릴리스의 자율성 레벨 (Autonomy Level)
- ☑ Level 1: AI가 정보를 제안(피드백), 인간이 모든 결정(운동 수행)
- ☐ Level 2: AI가 초안 생성, 인간이 편집 후 최종 결정

**이번 MVP는 Level 1**. 
**근거**: AI는 자세 개선 가이드를 '제안'할 뿐, 실제 운동을 수행하고 조절하는 주체는 사용자임.

## 2. 사용자 (Users)

### 2.1 주 사용자 (Primary)
- **페르소나**: 집에서 혼자 운동하며 자세 불균형을 걱정하는 2030 사회초년생.
- **핵심 니즈 3가지**:
  1. 실시간 자세 개선 피드백.
  2. 내 자세가 맞는지에 대한 수치적 근거.
  3. 어려운 장비 없이 바로 시작할 수 있는 간편함.
- **기술 수준**: 일반적인 웹 서비스 및 카메라 활용에 익숙함.
- **사용 빈도 (예상)**: 주 3~4회 (퇴근 후 운동 시).

## 3. 기능 요구사항 (Functional Requirements)

### F1. 실시간 관절 트래킹 및 시각화
- **설명**: 웹캠 영상에서 신체 관절을 찾아내고 스켈레톤을 렌더링함.
- **사용자 스토리**: "사용자로서, 내 몸이 어떻게 분석되는지 알기 위해, 화면 위 내 관절에 선이 그려지는 것을 볼 수 있다."
- **Acceptance Criteria**:
  - [ ] 웹캠 화면에 사용자의 관절 스켈레톤이 실시간으로 표시되어야 함.
  - [ ] 전신이 보일 때 주요 관절 포인트가 누락 없이 표시되어야 함.
- **우선순위**: ☑ Must

### F2. 스쿼트 자세 판정 및 피드백
- **설명**: 무릎/허리 각도를 계산하여 코칭 메시지 출력.
- **사용자 스토리**: "초보자로서, 자세를 고치기 위해, 실시간으로 무엇이 잘못되었는지(깊이 부족 등) 가이드를 받을 수 있다."
- **Acceptance Criteria**:
  - [ ] 측면 스쿼트에서 무릎 각도와 상체 기울기를 계산할 수 있어야 함.
  - [ ] 깊이 부족 / 상체 숙임 / 좋은 자세 중 하나로 판정할 수 있어야 함.
  - [ ] 준비 동작, 정지 상태, 관절 인식 실패(신뢰도 저하) 등 정상적인 운동 국면이 아닐 경우 판정을 보류하거나 '자세 정렬' 메시지로 전환해야 함 (오탐 방지).
  - [ ] 판정 결과에 따라 적절한 한국어 코칭 메시지를 출력해야 함.
- **우선순위**: ☑ Must

## 4. 비기능 요구사항 (Non-Functional Requirements)

### 4.1 성능
- **프레임 속도**: 로컬 환경에서 끊김 없이 관절 트래킹이 가능한 수준 유지.
- **초기 로딩 시간**: 모델 로드 포함 5초 이내.

### 4.2 비용 및 배포 목표
- **외부 API 비용**: 0원 (MediaPipe 및 OpenCV 활용).
- **운영 비용/배포 (Must/Optional 분리)**:
  - **Must (1단계)**: 로컬(Local) 환경에서 정상 작동 및 성공 기준 100% 충족.
  - **Optional (2단계)**: Streamlit Cloud 무료 호스팅 연동 (WebRTC 적용). 로컬 검증 완료 이후 후순위 고려.

---

## 5. 범위 밖 (Out of Scope)
- 런지, 푸쉬업 등 스쿼트 외 다른 운동 종목 (v2 이후 고려).
- 회원가입 및 개인별 운동 기록 DB 저장.
- 멀티 유저 동시 트래킹.
