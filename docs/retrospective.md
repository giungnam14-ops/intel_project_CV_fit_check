## 진행 중 기록 (Troubleshooting & Lessons Learned)

### 이슈 1: 한글 경로로 인한 MediaPipe 모델 파일 로딩 오류
- **발생 상황**: 영상 업로드 후 분석 시작 시 `pose_landmark_cpu.binarypb` 파일 누락 및 로드 실패 에러가 발생함.
- **오류 원인**: 프로젝트 경로에 한글 폴더명(예: `프로젝트_2번`)이 포함되어 있어, MediaPipe 내부 C++ 리소스 로더가 인코딩 문제로 모델 파일을 정상적으로 찾지 못함. 패키지 자체의 설치 문제가 아니었음.
- **시도한 해결 방법**:
  - 패키지 버전 변경 및 재설치 (경로 문제로 인해 효과 없음)
- **최종 해결책**: 프로젝트 폴더를 완전히 영문으로 된 경로(예: `C:\Users\User\Desktop\project_2\FitCheck-AI`)로 변경한 뒤, 기존 `.venv` 폴더를 삭제하고 가상환경을 처음부터 재설치함.
- **결과**: MediaPipe Pose 모델이 정상적으로 초기화되고 영상 업로드 기반 자세 인식이 안정적으로 동작함을 확인함.

### 레슨 2: 단순 평균값 피드백의 한계점 극복
- **발생 상황**: 초기에는 무릎 각도와 상체 기울기의 전체 평균값을 기준으로 자세를 판단하려 했으나, 영상 길이나 휴식 시간에 따라 평균값이 왜곡되는 현상이 발생함.
- **개선 방법**: 평균값이 아닌 스쿼트의 '최저점 무릎 각도'와 '최대 상체 기울기'를 기준으로 자세 코칭 룰 엔진을 개편함. 그 결과 동작의 가장 취약한 순간을 정확히 포착할 수 있었음.

### 레슨 3: CSV 누적 저장 형식 깨짐 문제 해결
- **발생 상황**: 데이터를 축약된 문자열이나 단순 텍스트로 저장하려다 보니 `...`와 같이 값이 생략되며 데이터가 심각하게 손상됨.
- **해결 방법**: 순수 Pandas DataFrame 기반 `to_csv` 처리 방식으로 전면 개편하고, 동일한 파일명이 있을 경우 행을 삭제한 후 교체(최신 덮어쓰기)하도록 구현함. `utf-8-sig` 인코딩을 강제하여 한글 코칭 메시지 깨짐 현상을 원천 방지함.

### 레슨 4: 스쿼트 카운팅 기능의 현실적인 접근
- **배운 점**: 무릎 각도를 활용한 상태 머신 카운팅 기능을 구현했으나, 완벽한 운동 기록 용도로는 카메라 각도나 조명 등에 신뢰도가 크게 의존함을 배움.
- **보완 전략**: 이를 완벽한 카운터로 포장하기보다는 "운동 흐름을 파악하는 1차 기능"으로 정의하고, 카운팅 신뢰도(`HIGH/MEDIUM/LOW`) 지표를 함께 보여주어 사용자가 상황을 투명하게 이해하고 보조 지표로 활용할 수 있도록 보완함.
