# 실시간 웹캠 분석 1차 테스트 기록

**테스트 일자**: 2026년 5월 22일  
**테스트 환경**: 로컬 OpenCV 기반 웹캠 실시간 스트리밍  
**테스트 목표**: 실시간 웹캠 입력을 통한 자세 코칭 기능의 기초 검증

---

## 현재 상태

### ✅ 확인된 기능
- **실시간 웹캠 화면 출력**: OpenCV `cv2.VideoCapture(0)` 연동 확인
- **Streamlit UI 연동**: 웹브라우저 기반 실시간 피드 표시 확인

### 🔄 검증 진행 중
- **MediaPipe 스켈레톤 오버레이**: 웹캠 프레임 위에 관절 위치 표시 여부 확인
- **실시간 각도 계산**: 무릎 각도, 상체 기울기 실시간 연산 동작 확인

### ⏳ 예정 사항
- **실시간 피드백**: GOOD/NOT_DEEP/LEAN_FORWARD/LOW_VISIBILITY 판정 동작 확인
- **자세 안정성 분석**: 5프레임 이동평균 스무딩 동작 확인
- **운동 흐름 추적**: 스쿼트 반복 카운팅 검증 (향후 고도화)

## 테스트 실행 방법

### 웹캠 앱 실행
```bash
streamlit run app/webcam_app.py
```

### 테스트 절차
1. 브라우저에서 Streamlit UI 접속 (기본값: http://localhost:8501)
2. **"🎬 웹캠 시작"** 버튼 클릭
3. 웹캠 활성화 후 각 시나리오별 동작 수행
4. 화면에 표시되는 정보 관찰:
   - 관절 포인트 및 스켈레톤
   - 무릎 각도 (Knee Angle)
   - 상체 기울기 (Torso Angle)
   - 실시간 피드백 메시지
