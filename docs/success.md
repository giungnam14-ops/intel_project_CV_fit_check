# 성공 지표 (Success Metrics)

> **작성 시점**: Day 3
> **상태**: 성공 지표 정의 완료 (구현 후 측정 예정)
> **무엇이 성공인지, 어떻게 측정할 것인지를 정의한다.**

---

## 1. 북극성 지표 (North Star Metric)
> **"사용자가 AI 코칭 피드백을 통해 자신의 스쿼트 자세를 실시간으로 인지하고 개선 포인트를 이해하였는가?"**
- **검증 질문**: 사용자가 테스트 직후 "다음 스쿼트에서 무엇을 바꿀 것인지" 구체적으로 답변할 수 있는가?

---

## 2. MVP 기능 성공 기준 (Functional Success)
3주 초보 팀의 개발 목표에 맞춘 핵심 기능 통과 조건입니다. (로컬 환경 기준)

- **a. 시각화**: 웹캠 화면에 관절 스켈레톤이 실시간으로 정상 표시된다.
- **b. 계산**: 측면 스쿼트 수행 시 무릎 각도와 상체 기울기가 실시간으로 계산된다.
- **c. 판정**: 계산된 각도를 기반으로 `깊이 부족` / `상체 숙임` / `좋은 자세` 중 하나를 정확히 판정한다.
- **d. 피드백**: 판정 결과에 따른 적절한 한국어 코칭 메시지가 화면에 즉시 출력된다.
- **e. 종합 정확도**: 
  - **단일 영상 기준**: 준비된 5개의 테스트 영상 중 4개 이상에서 의도한 피드백이 정확히 출력된다.
  - **오탐 방지 (False Positive)**: 휴식이나 준비 동작에서는 명백한 오탐(잘못된 코칭 피드백)이 반복적으로 발생하지 않아야 한다 (판정 보류 기능 동작).
  - *(향후 고도화 지표)*: 1세트(15회) 연속 스쿼트 시 12회 이상 올바른 판정(정확도 80%), 완전한 오탐 0회 달성.
- **f. 배포 환경**: 위 기준들은 **로컬(Local) 환경**에서 통과하는 것을 MVP의 필수(Must) 성공 조건으로 하며, 클라우드(WebRTC) 연동은 선택(Optional) 후순위 목표로 분리한다.

---

## 3. 발표 시연 성공 기준 (Presentation Success)
최종 발표 및 데모 시 시각적으로 보여주어야 할 목표입니다.

- **실시간성**: 로컬 환경에서 시연 시, 사용자의 움직임과 화면 속 스켈레톤/피드백 사이의 이질감이 느껴지지 않는 수준의 반응 속도를 유지한다.
- **직관성**: 발표를 보는 청중이 수치(각도)를 보지 않더라도, 메시지와 색상 변화만으로 현재 자세의 좋고 나쁨을 즉시 이해할 수 있다.
- **안정성**: 시연 중 프로그램이 강제 종료되거나 캠 인식이 중단되는 현상 없이 매끄럽게 동작한다.

---

## 4. 검증 완료 항목 (Verified Successes)
- [x] **영상 업로드 기반 자세 분석**: 5개 테스트 영상 중 4개 의도 일치, 1개 한계 사례로 분류 성공 확인.
- [x] **스무딩 적용**: 5프레임 이동평균을 적용하여 관절 인식 오류(튐 현상) 완화.
- [x] **스쿼트 카운팅 1차 구현**: 무릎 각도 기준 상태 머신 동작 확인.
- [x] **카운팅 신뢰도 표시**: HIGH/MEDIUM/LOW 기준을 통한 운동 흐름 해석 보조 지표 도입.
- [x] **결과 리포트 UI 개선**: 시각적 가독성이 향상된 초보자 맞춤형 평가 피드백 대시보드 완료.
