# FitCheck AI 프로젝트 요약서 (Project Summary)

## 1. 프로젝트명
FitCheck AI

## 2. 한 줄 소개
웹캠 하나로 실시간 관절 각도를 분석하여, 일상적인 홈트레이닝 스쿼트 자세를 점검하고 코칭해 주는 컴퓨터비전 기반 자세 코칭 솔루션

## 3. 현재 프로젝트 상태
- **상태**: 영상 업로드 기반 MVP 구현 및 5개 테스트 영상 검증 완료
- **UI 목업**: `mockup/` 폴더에 HTML/CSS 기반의 정적 화면 시안이 구축되어 있습니다.
- **주요 성과**: MediaPipe와 OpenCV를 활용한 스쿼트 자세 평가(최저점 무릎 각도, 최대 상체 기울기 기준), 5프레임 스무딩, 스쿼트 카운팅 기능 및 직관적 결과 리포트 UI가 작동합니다.

## 4. 해결하려는 문제
홈트레이닝 초보자는 운동 중 자신의 자세가 맞는지 실시간으로 알기 어렵습니다. PT를 받지 않는 이상 자세 불균형이나 잘못된 동작으로 인해 관절(무릎, 허리)에 무리가 갈까 불안함을 느끼며, 이로 인해 운동의 성취감과 동기가 저하되는 문제를 겪고 있습니다.

## 5. 기존 방식의 한계
초보자들이 현재 주로 사용하는 방식은 거울을 보거나 스마트폰으로 전신 영상을 촬영한 뒤, 운동이 끝난 후 유튜브 영상과 대조하는 것입니다.
- 거울을 보며 운동하면 고개가 돌아가 오히려 자세가 틀어집니다.
- 촬영 영상은 사후 검토 방식이므로 운동 중에 즉각적인 자세 교정이 불가능합니다.

## 6. 제안하는 서비스
특별한 장비나 유료 센서 없이, 사용자의 노트북/PC 웹캠만으로 스쿼트 자세의 안정성을 실시간 분석하여 초보자 맞춤형 즉각 피드백을 제공하는 서비스입니다. 의료적 진단이 아닌 일상적인 '자세 코칭'과 '올바른 운동 습관 형성'을 보조하는 데 목적을 둡니다.

## 7. 핵심 기능 (설계 기준)
- **실시간 관절 트래킹 및 시각화**: 웹캠 화면 내 사용자 신체 위에 주요 관절 포인트와 스켈레톤 라인을 렌더링하도록 기획되었습니다.
- **국면(Phase) 인식 및 각도 계산**: 사용자가 서 있는지, 앉는 중인지, 최저점인지 등 스쿼트의 국면을 파악하고, 무릎과 상체의 꺾임 각도를 계산하여 안정성을 판단하도록 설계되었습니다.
- **맞춤형 즉시 피드백**: '깊이 부족', '상체 숙임', '안정적인 자세' 등 판정 결과에 따른 초보자 맞춤형 코칭 메시지를 화면에 노출하도록 설계되었습니다.

## 8. 기술 설계 요약
- **Application**: Streamlit 기반 웹 인터페이스
- **AI/CV Engine**: OpenCV (영상 처리) / MediaPipe Pose (랜드마크 추출)
- **로직 파이프라인**: 5프레임 이동평균 스무딩 -> 최저점/최대 기울기 각도 연산 -> 기하학적 룰(Rule) 기반 자세 판별 -> 상태 머신 기반 카운팅 -> Streamlit 리포트 출력
- **프라이버시**: MVP 설계 기준에서는 영상 데이터나 추출된 좌표를 별도 서버나 DB에 저장하지 않고, 로컬 실행 환경에서 처리하는 것을 원칙으로 합니다.

## 9. 자세 판정 기준 요약 (설계 기준)
단순 블랙박스 딥러닝이 아닌, 명확한 임계값을 가지는 룰 기반(Rule-based) 판정을 통해 일관성 있는 피드백을 제공하도록 설계되었습니다.
- **깊이 부족**: 최저점(Bottom) 도달 시 무릎 각도가 $110^\circ$ 이상일 때 ("엉덩이를 조금만 더 뒤로 빼볼까요? 의자에 앉는다는 느낌으로!") 피드백 노출
- **상체 숙임**: 동작 진행 중 상체 기울기가 수직 대비 $45^\circ$ 이상 지속적으로 꺾일 때 ("허리를 조금 더 곧게 펴고 진행해보세요.") 피드백 노출
- **오탐 방지 (안정화)**: 신뢰도(Confidence) 0.5 미만 시 판정 보류, 스무딩(최근 5프레임 이동 평균) 및 준비 동작 필터링을 통해 잘못된 피드백을 방지하도록 설계되었습니다.

## 10. 데이터 수집 및 평가 계획 (설계 기준)
- **MVP 평가 목표**: 팀 내 자체 촬영을 통해 10~20개의 테스트 영상을 수집할 예정입니다.
- **데이터 분리**: 임계값을 맞추는 데 사용하는 '튜닝 데이터'와, 코칭 판정이 의도한 결과와 일치하는지 확인하는 검증 데이터로 격리하여 활용할 계획입니다.
- **평가 기준**: 검증 데이터에서 '명백한 오탐이 반복적으로 발생하지 않는지', 그리고 단일 영상 테스트 시 의도한 코칭 피드백이 적절히 출력되는지 검증할 예정입니다.

## 11. 차별점 (문서 기반 MVP 단계의 가치)
- **무비용 & 경량화**: 유료 Pose API에 의존하지 않고 오픈소스 MediaPipe를 활용하여 추가적인 API 운영 비용이 발생하지 않도록 설계되었습니다.
- **판정 근거 설명 가능**: 수치 기반 룰 엔진을 사용하여 왜 특정 피드백이 발생했는지 각도 데이터로 설명 가능한 구조입니다.

## 12. 향후 개선 계획 (고도화 항목)
1. **카운팅 임계값 튜닝**: 다양한 체형 및 영상 조건에 맞춰 상태 전환 기준 각도 최적화.
2. **LOW_VISIBILITY 기준 보완**: 단순 인식률을 넘어 환경 노이즈로 인한 신뢰도 하락을 식별.
3. **실시간 웹캠 분석**: 영상 업로드 기반 MVP 검증이 완료됨에 따라 실시간 웹캠 코칭 기능으로 발전.
